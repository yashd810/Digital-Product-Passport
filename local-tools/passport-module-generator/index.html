2. Sections And Fields

Add fields once. The generator uses them for both the module file and dictionary artifacts.

Fields CSV v2 preserves editable inputs and nesting. Section path is the authoritative JSON label path, for example ["Product identity", "Materials"]. Exported auto-filled columns—including key paths, field/column keys, semantic slugs, unit keys, and schema metadata—are reference-only and are regenerated from the actual imported labels, UI/data types, and units. Older flat CSV files remain supported as top-level sections.

3. Semantic Class Graph

Define reusable classes, class-to-class properties, controlled enums, explicit IRIs, and SHACL cardinalities.

Semantic graph CSV v2 is lossless. It keeps stable keys, explicit IRIs, field-source links, enum overrides, and UI metadata. Replacing it changes only the graph; Sections And Fields stay in place. Build the first layer only when you intentionally want to create graph links from Part 2, and use Custom only for concepts not represented there.
